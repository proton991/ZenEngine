# P6 radiance-cache reflections

2026-10-10. Implements [P6](../HardwareRayQueryEnvironmentLightingPlan.md#p6-glossy-reflections-from-the-radiance-cache). **The P6 exit is met on the RTX 5080:** the RT-tier fixture gate passes, moving reflections track the current camera, and both compute-tier choices are measured.

## Implementation

- The existing GGX lobe ray now requests the closest hit when `voxel_gi_reflections=true`. Both providers read P5's base-level, coverage-normalized, facing-checked radiance cache. Rejected lookups contribute zero. Indirect intensity is applied once by the shared lookup.
- The specular texture stores `C = (1 - S) H` in RGB and `S` in alpha. Temporal and spatial reconstruction operate on C directly, avoiding division by a noisy hit fraction and multiplication of independently estimated values. Composition is `(S * prefilteredEnvironment + C) * splitSum * AO`.
- C has separate luminance moments, history length and reprojection. Its static limit is 16 frames, or 4 below roughness 0.2. During camera motion, surfaces below roughness 0.4 project the virtual point `receiver - view * hitDistance` into the previous camera. Taps require matching receiver identity, plane, normals, roughness and reflected distance. A current same-surface neighbourhood supplies distance when a stochastic ray misses; it supplies no radiance. Static cameras use the equivalent surface reprojection without stochastic distance rejection. Reference mode uses same-pixel accumulation.
- The existing responsive cache-change policy is shared with diffuse bounce: correlated current/previous cache lookups update history through changing light. For reflections, the neighborhood clamp applies only during camera motion. With one ray per pixel it emptied valid dim history after cache changes, and the correlated update already handles those (P6 review, below). Reflection enablement and indirect-intensity changes invalidate C without invalidating sky. If the previous-cache allocation fails, hit-radiance histories restart on an injection instead of treating the current cache as the previous generation. The spatial filter uses C's luminance variance and rejects roughness boundaries; its footprint shrinks with roughness.
- Deferred and covered opaque/masked forward receivers compose the signal. Clearcoat, anisotropy and sheen reuse the base-lobe visibility and hit radiance, an approximation. Analytic specular and unsupported per-surface layers retain their existing paths. Reflections require specular occlusion to be enabled.
- `voxel_gi_reflections=auto|true|false`, also in the editor. The default `auto` enables reflections with the hardware provider and keeps occlusion only (`H = 0`) on the compute tier, as P5's bounce source does; P8 measures and chooses the compute-tier default. `true` and `false` force either path on any tier.

Below roughness 0.2, detail remains limited to the isotropic voxel cache and the short history is noisy. There is no material shading at the reflection hit and no mirror-quality claim. Hits outside the cache and rejected back-side lookups return zero, as in P5.

### Sampling correction

The CPU glossy comparison exposed a pre-existing GGX rejection bias. Candidate and acceptance values used rotated R2 sequences with the same increment; their first coordinates were correlated at each pixel. One sampled receiver differed by 2.66 percentage points from the CPU visibility integral. The first candidate remains stratified; independent counter hashes now supply acceptance and retries. A native regression checks the analytic GGX cap integral at roughness 1 and normal incidence: the fraction above cosine 0.5 is `(0.5 - log(4/3)) / (1 - log(2))`. The same native suite continues to check exactly unoccluded and enclosed visibility.

### Storage and diagnostics

When enabled, reflections add one RGBA32F history per side (32 bytes/pixel total), an RG32F raw distance/rejection texture and an RGBA16F previous-cache sample texture (16 transient bytes/pixel). They reuse the existing specular RGB channels and the fourth filter-variance channel. Disabled reflections use 1×1 placeholders and skip their work. The previous base radiance volume is now retained whenever reflections or ray bounce resolve on: 16 MiB at 128³, shared when both signals are enabled. With the `auto` defaults, the compute tier allocates neither. These are format counts, not peak residency or P8 qualification.

Capture metadata is version 3; the seven lighting components and thirteen hybrid float4 records keep their sizes. Hybrid components 4/5 contain raw/reconstructed C and S. Component 12 contains identity bits, raw mean hit distance, rejected lookup count and C history length. Metadata states this convention, the resolved reflection enablement and roughness cutoff. Profiling records the reflection setting.

## Verification

Windows, RTX 5080, MSVC Debug, driver raw version `2588114944`, Vulkan SDK 1.4.357. Captures use synchronization validation with implicit layers disabled. Evidence is under `build/p6/`; the portable summary is [P6Verification.json](P6Verification.json). All native fixture runs reject application, Vulkan and synchronization errors.

- RenderCoreTest: **576 passed**. The history regression includes reflection enable/disable, radiance changes, intensity changes, failed frames, independent views and resize.
- ConeVoxelGIIntegrationTest: **20 passed** across inline/threaded and graphics/async modes, including the analytic specular-sampling regression and shared hit-radiance facing/coverage tests.
- All **121** SceneRenderer/VoxelGI SPIR-V variants pass `spirv-val --target-env vulkan1.2`. The demo and editor UI build.
- **14 final allocation/settings regressions pass**, including failed previous-cache allocation and retry. Final native smoke checks combine automatic RT ray bounce with reflections (C and S are byte-identical to the isolated reflection run) and verify that legacy mode records no cache-snapshot pass. Numerical captures precede these final failure/legacy guards; the successful hybrid shader path is unchanged.

The updated glossy fixture is a roughness-0.2 floor facing a finite coloured wall and a point light. The old placeholder put a wall through the camera, with its owner normal facing away from the light. Additional fixtures cover roughness 0.1, an empty environment-lit floor, an enclosed lit room, forward clearcoat, and a constant emissive wall. The frozen limits are unchanged.

The motion sequence translates the camera laterally by 0.003 normalized world units each frame for 32 frames. Frames 8/16/24/32 are captured during motion, before any settling frame. Static 64×1024-sample references at the identical poses run afterward. Reports include reflection-channel errors, dark-region energy and fitted reflection displacement; paired images are inspected for trails. This sequence does not establish every camera trajectory or curved-receiver case.

**Motion.** Every captured moving frame fits the reference reflection at **zero pixel displacement**, at roughness 0.2 and 0.1. The initial surface-only implementation lagged by two pixels in the 320×180 probe; hit-distance reprojection removed it. The paired final images show noise around the reflection boundary, without a displaced old reflection. This is motion-position evidence, not a claim that the moving images meet the static noise budget: all-receiver C RMS is 9.4–9.7% at roughness 0.2, and 7.2% at 0.1. Histories during motion are bounded at 8 and 4 frames respectively.

**Below the cutoff.** At roughness 0.1 the static all-receiver result is bias +0.23%, RMS 4.36%, P99 17.60%; the floor-only P99 is **31.17%**, above the static shipping threshold. This added stress case is reported separately from the frozen roughness-0.2 glossy fixture. Mirror-quality detail and smooth low-sample tails are not supplied by this cache.

**Independent lobe reference (P6 review).** `tools/ground_truth_specular.py` integrates each receiver's GGX lobe with Mitsuba on CUDA. Receivers come from the reference capture's G-buffer, on every second pixel. It uses visible-normal samples with G1 weights, triangle hits with alpha continuation, and no engine voxels. Before any comparison it passes five analytic cases:
- open sky (S exactly 1);
- the weighted lobe's closed-form cap fraction at roughness 1;
- an emissive ceiling (C equal to its emission);
- a second primitive (hit identification);
- a back-facing emitter (C exactly 0).

It replaced the Embree CPU spot checks, which sampled 628 and 540 receivers. Both fixtures together take a few seconds on the RTX 5080.

**Reflected emission.** The CPU check reported −0.44% on its sparse grid. Every second pixel gives −1.43%, so the sparse grid had missed most of the error.
- **Where it is.** The shortfall sits where rays see the wall's interior (local −1.87%); receivers at the reflection's edges are at −0.58%.
- **Cause.** S agrees with the reference there to about 0.0003. So the difference is in the cached radiance read at the hits, the cache approximation P5 reports per cause, not in the hit estimator. A likely cause is cells where the wall meets the floor being owned by the floor.
- **Limit.** No frozen limit covers C. The earlier 0.5% gate was borrowed from the analytic fixtures and is not applied; the closest frozen analogue is P5's one-bounce limit (10% bias, differences reported per cause).

**Light changes (P6 review).** The P5 light-change harness runs on the roughness-0.2 glossy floor: light moved, all lights off, the floor's material made emissive and restored, and a light orbiting for 64 frames. Each stage has a fresh 64×1024-sample reference. The plan's light-change and continuous-motion limits were extended to the reflection channel before measurement.
- **First run.** Bias stayed within about 1% and the orbit passed, so reflections did not smear.
- **Floor failures.** The floor region failed frame-8 P99 after the move (21.15%) and after emission on (20.17%).
- **Cause.** Emission on the floor's own material does not change the floor's reflection at all, yet floor P99 rose from 11.8% before the change to 13.6%, 18.7% and 20.2% at frames 1, 4 and 8. Dark regions fell to −85% of the reference. The shared responsive clamp to the current 9×9 neighborhood was emptying valid history: with one ray per pixel, a dim reflection often has no hit anywhere in that neighborhood, and the box then collapses to zero.
- **Rejected fix.** Removing the 8-frame cap instead made no difference, which confirmed it was not the cause.
- **Fix.** Reflections now apply the clamp only during camera motion. The correlated update alone handles cache changes, including a light going out. Diffuse bounce keeps the clamp; its four rays per pixel rarely leave a neighborhood empty, and P5's gates pass with it.

Final run, glossy floor at roughness 0.2, all receivers and floor region, bias / RMS / P99 / unexpected zeros. The same-pixel references are converged at the changed lighting; the limits are 2 / 8 / 20 / 0.

**Provenance.**
- **Light-change runs** (`build/p6/{hardware,voxel}/lights`) use the final shaders. The earlier runs are kept as `lights-before-clamp-fix` and `lights-rejected-cap-change`.
- **Remaining P6 captures** precede the clamp change. It acts only in the eight frames after a cache change while the camera is still, and those captures are 56 or more frames past any such change.
- **Camera-motion path** is unchanged.

**RT cost.** Summed GPU medians for HybridTrace, HybridTemporal, five HybridFilter passes and SceneLighting, occlusion only / reflections: **3.93 / 4.24 ms** for the glossy floor, **4.11 / 4.39 ms** for the closed room. These Debug/validation measurements compare the feature cost, about 0.3 ms here. They are not whole-frame times or P8's 1080p Release qualification.

### Compute tier (`--disable-rt`)

The same fixtures, resolution and captures run with the voxel provider and no enabled RT features. The glossy floor passes against its own converged voxel reference: all-receiver bias **+0.05%**, RMS **1.78%**, P99 **8.10%**, no unexpected zeros. The closed room is **−0.19% / 0.90% / 4.06% / 0**. Enclosed sky and S remain exactly zero in deferred and forward, with nonzero reflected scene light. The open-PBR and zero-indirect checks pass; sampled moving frames fit at zero displacement.

The differences against the independent CUDA lobe reference remain material:
- **S:** mean absolute error **6.5 pp** over 93,088 receivers, with receivers up to **100 pp** off (the earlier CPU grid saw 1.77 pp mean and 78 pp maximum).
- **Reflected emission:** bias **+16.0%**.

These fail the RT reference limits and are reported, as the plan requires for voxel geometry. Occupied starts, displaced hit points and cache-cell ownership remain compute-tier limitations; matching the voxel reference does not erase them.

Summed GPU medians, occlusion only / reflections: **6.16 / 6.11 ms** (floor) and **6.90 / 7.14 ms** (closed room). The floor difference is too small to claim a speedup; the closed-room increment is 0.24 ms. These measurements leave both paths available for P8's platform/preset decision.

### Remaining scope

P8 owns the compute-tier choice, presets and total memory qualification. RX 7900 XT, a physical non-RT GPU and MoltenVK are unverified. This phase does not close P4's remaining full-scene sky reconstruction gates or validate every motion/deformation/environment combination. The independent lobe reference covers every second pixel of each fixture; mirror-sharp and real-material reflections have no independent truth yet.

## Reproduction

Use Python with `tools/requirements-gi-quality.txt`. Run config-mutating capture commands sequentially.

```powershell
$env:_CL_='/Z7'
build/voxel-gi-build.cmd SpvShaders scene_renderer_demo RenderCoreTest ConeVoxelGIIntegrationTest ZenEditorUI
python tools/validate_hybrid_reflections.py --exe build/x64-windows-msvc-debug/bin/scene_renderer_demo.exe --output build/p6/hardware --provider hardware --capture
python tools/validate_hybrid_reflections.py --exe build/x64-windows-msvc-debug/bin/scene_renderer_demo.exe --output build/p6/voxel --provider voxel --capture
```

Omit `--capture` to re-analyze saved evidence. The gate renders the CUDA lobe reference after all captures finish (`python tools/ground_truth_specular.py --self-test` checks it alone). `compare_hybrid_gi.py --channel reflection` compares C. `--capture-reflection-motion=PREFIX` runs the native camera sequence. The compute run uses `--disable-rt` and forces reflections on; its comparison with the triangle reference is reported, not an acceptance claim for voxel geometry.
